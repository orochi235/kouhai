kouhai

what your agents owe you

Ask a Claude Code session something in the middle of a task and the answer scrolls away with the task. kouhai keeps a ledger of the questions you ask and the instructions a session hasn't carried out yet. Each one stays owed until the agent settles it with a note you can read later, away from the chat. 

brew install orochi235/tap/kouhai
brew services start kouhai
claude plugin marketplace add orochi235/kouhai
claude plugin install kouhai@kouhai

Try the demo Source

The demo is the real page over a made-up ledger, with nothing behind it. A few items arrive and get settled while you watch, and the controls work, but only on your copy in that tab.

What gets filed

Item Filed when Settled as
q-17 question you ask the agent something directly answered, dropped, deferred
t-18 task you give an instruction it won't finish this turn done, dropped, deferred

The agent files each item with a short slug, so #cost-of-slugs works as well as q-17 in a later prompt. An instruction it carries out in the same turn isn't filed. Deferred means moved to a TODO entry or an issue, and the note says where. Claude still answers in chat as usual. The ledger is the copy that stays.

Reading it

The page sorts the ledger by repo, in each repo's own colors. An answer leads with a one-sentence verdict, then a note that can carry code, tables and diagrams. It says whether the answer was measured, read from the code or only inferred, and the page flags it once a file it cites has changed. A follow-up question nests under the answer it follows. The next session in a repo is told what is still owed there.

How it is put together

A Claude Code plugin gives the agent the filing rule on every prompt and two MCP tools, take and settle. Its hooks write straight to a local SQLite file, so nothing is lost when the page isn't running. A small Node daemon serves the page and pushes each change to it. The page is React, laid out with windease, and the menu bar item is made with perch.
